# Topological Visual Toolkit

A mathematical application containing six university project subprograms related to metric/topological concepts, function distances, Bernstein approximation, preimages and images of mappings.

## Installation

```bash
pip install -r requirements.txt
```

## Running

```bash
streamlit run app.py
```

## Features

1. Finite Metric Spaces
2. Supremum Distance on an Interval
3. Supremum Distance on a Rectangle
4. Bernstein Approximation
5. Scalar Function Preimage
6. Vector Mapping Images and Preimages
